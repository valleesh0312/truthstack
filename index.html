Data Integrity
Does the data add up?
GST vs bank credits — GSTR-3B declared ≠ 12-month actuals
GSTR-1 suppression — outward supply declared but not reported
Invoice ↔ GST ↔ bank — HSN codes, taxable value, payment reference
Document staleness — ITR and financials beyond acceptable age
Broken evidence chain — data point untraceable to originating source
Fraud
Is this genuine?
Duplicate invoice — same invoice at multiple lenders. P0 auto-reject.
Invoice fabrication — font anomalies, metadata tampering, template reuse
Circular transactions — funds returned through layered transfers A→B→C→A
GSTIN / promoter flags — cancelled GSTIN, RBI defaulter, MCA strike-off
Shell company network — director-linked shell entities, shared bank accounts
Credit Profile
Does the case hold?
DSCR vs bank actuals — stated financials vs 12-month cash flows
Single-buyer concentration — 100% receivables, no verified payment history
Pre-application spike — volume surge 2–3 months before submission
Profile incoherence — repayment unmodellable when sources conflict
Rules catch reconciliation failures. Governed AI catches fabrication and behavioural fraud. Both layers run on every file.
